# Changelog

## 0.1.0（未发布）

首个公开版本，由内部版本整理开源：

### 安全
- 认证实闸（JWT 强制 + 租户上下文唯一来源）；删除匿名兜底租户
- 内部接口共享密钥（X-Internal-Token）；高危 reset 端点默认禁用
- 生产数据库凭据与 JWT 默认密钥全部 env 化；生产档密钥 fail-fast

- 过账并发正确性：原子增量 + 版本条件（原乐观锁为死逻辑）、双过账竞态修复、余额更新失败不再静默

- 工资金额解析量词紧邻修复（「3000元…2万元」不再误乘）

- 重建父 pom（仓库原本缺失，净克隆不可构建）；jjwt 0.11.5；Boot 2.7.18 / JDK 17

- H2 profile + 演示数据；73 个单元/集成测试；jacoco 覆盖率门（voucher/common ≥60%）
